# AC Sehat — Versi Web/PWA

## Isi paket
- Dashboard service
- Data pelanggan
- Data pekerjaan/service AC
- Teknisi
- Status pekerjaan
- Foto sebelum dan sesudah
- Biaya service
- Laporan dan cetak/PDF
- Bisa dipasang sebagai aplikasi PWA di Android

## Cara mencoba
1. Ekstrak ZIP.
2. Buka `index.html` di browser untuk uji tampilan.
3. Untuk tombol "Pasang Aplikasi" dan mode PWA/offline, file harus dijalankan melalui HTTPS atau localhost.
4. Data versi ini disimpan di browser HP menggunakan localStorage.

## Catatan penting
Versi ini adalah paket web/PWA yang sudah bisa diuji. Ini belum merupakan APK Android native dan belum menggunakan database online bersama. Untuk pemakaian banyak teknisi dengan satu database pusat, tahap berikutnya perlu backend/database online.
